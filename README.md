## Our Mods

### Core & Framework

| Mod | Description |
|-----|-------------|
| **506IRRU Core** | Core utility framework |
| **506IRRU All in One** | Meta-mod that bundles all 506th mods as dependencies into a single package for easy loading |
| **506IRRU Factions** | Faction definitions, configurations, and squad leader map marker visibility controls |
| **506IRRU Conflict** | Custom Conflict Edits |
| **506IRRU Mission Templates** | Mission and world templates with customizable GM budget controls |

### Medical & Injuries

| Mod | Description |
|-----|-------------|
| **506IRRU Medical** | Medical system featuring CPR, casualty inspection, and character damage management |
| **506IRRU Respiratory** | Respiratory injury system — pneumothorax (collapsed lung) mechanics and chest seal treatments |

### Equipment & Weapons

| Mod | Description |
|-----|-------------|
| **506IRRU Loadouts** | Comprehensive loadout management — save/load character inventories, weapon configs, and gear setups |
| **506IRRU Equipment** | Equipment configurations including tactical lasers (AN/PEQ-16) and optical magnifiers |
| **506IRRU Weapons** | Weapon configurations and system modifications |

### Vehicles & Aircraft

| Mod | Description |
|-----|-------------|
| **506IRRU Vehicles** | Vehicle configurations and related assets |
| **506IRRU A10C** | A-10C Warthog flight display and HUD components |
| **506IRRU Airplane Props** | Decorative aircraft assets (FA-18D/E variants) for airfield and base setups |

### Communication & UI

| Mod | Description |
|-----|-------------|
| **506th IRRU Enhanced Radio** | Enhanced VON system with directional audio routing and customizable radio beep types |
| **506th IRRU Custom Name Tags** | Player name tags displaying rank, affiliation, and identifier information |
| **506IRRU Ticket System** | In-game support ticket system with chat command integration |
| **506IRRU GM Contact View** | Enhanced Game Master contact view with status-based color coding for player markers |

### Artillery

| Mod | Description |
|-----|-------------|
| **506th IRRU Mortars** | Mortar artillery system with a fire solution computer for calculating firing solutions |

### Game Master Tools

| Mod | Description |
|-----|-------------|
| **506IRRU Add Forces Ares Slot** | Adds ForceGM group slots that grant Game Master permissions to designated forces groups |
